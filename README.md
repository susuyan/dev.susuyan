Personal knowledge base built with [Fumadocs](https://fumadocs.vercel.app).

## 快速开始

```bash
# 克隆项目
git clone https://github.com/susupang/dev.susuyan.git

# 进入项目目录
cd dev.susuyan

# 安装依赖
bun install

# 启动项目
bun dev
```

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- Fumadocs
- TypeScript

## Development

```bash
bun install
bun dev
```

## Build

```bash
bun build
```

## 项目结构

```
.
├── app/            # Next.js app router
├── content/        # Fumadocs content
├── components/     # React components
├── lib/           # Utilities
└── public/        # Static assets
```
