# 欢迎来到 susuyan 的数字花园

> 这里不是冷冰冰的技术博客，而是一个有温度的个人知识空间。
> 记录思考、分享工具、沉淀经验 —— Slow is Fast。

## 关于我

我是 **susuyan**，一名资深 iOS 开发者。

热爱构建优雅的工具和产品，相信好的设计源于对细节的执着。
在这个数字花园里，我记录技术探索、工作流优化、以及对工具和效率的思考。

## 花园里有什么

- **Config** — 我的工具配置和 dotfiles
- **Focus** — 保持专注的方法和实践
- **How I Code** — 编程哲学和代码风格
- **Meaning** — 对技术和生活的思考
- **Music** — 音乐与创作的连接
- **Workflow** — 效率工作流和自动化
- **Values** — 核心价值观和设计原则

## 设计哲学

这个站点遵循几个核心原则：

1. **温暖手工感** — 极简框架 + 柔和质感，避免工业化冷漠
2. **克制视觉** — 用排版和间距说话，拒绝花哨装饰
3. **专注阅读** — 内容为主，去除干扰
4. **个人特质** — 保留手工痕迹，避免完全模板化

## 技术栈

- [Next.js 16](https://nextjs.org/) — React 框架
- [Fumadocs](https://fumadocs.vercel.app/) — 文档站点框架
- [Tailwind CSS 4](https://tailwindcss.com/) — 样式系统
- [Bun](https://bun.sh/) — 包管理器
